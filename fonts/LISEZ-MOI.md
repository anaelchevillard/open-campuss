# Polices de Campuss

Toutes les polices sont auto-hébergées (aucun appel à un service de polices).

- `massilia/` : titres et logo. Remplacée ici par Source Sans 3, voir `massilia/LISEZ-MOI.md`.
- `source-sans-3/` : texte courant. Source Sans 3, Adobe. Licence SIL OFL 1.1 (`LICENSE.txt`).
- `source-serif-4/` : texte à empattements. Source Serif 4, Adobe. Licence SIL OFL 1.1 (`LICENSE.txt`).
- `atkinson-hyperlegible-next/` : lecture adaptée. Atkinson Hyperlegible Next, Braille Institute. Licence SIL OFL 1.1 (`LICENSE.txt`).
- `opendyslexic/` : remplace le texte en mode dyslexie. OpenDyslexic, Abbie Gonzalez. Licence SIL OFL 1.1.
- `name/` : polices des noms personnalisés (Barlow Condensed, Caveat, JetBrains Mono, Nunito), licences dans le dossier.

Seuls les fichiers `.woff2` servent au build.
