# Massilia : police de remplacement

Le site officiel utilise **Massilia** (Matthieu Salvaggio, Blaze Type), une police commerciale dont la licence
n'autorise pas la redistribution du fichier. Elle n'est donc pas dans ce dépôt.

`massilia-vf.woff2` est ici une copie de **Source Sans 3** (Adobe, SIL OFL 1.1, voir `../source-sans-3/LICENSE.txt`),
pour que le build et l'affichage fonctionnent sans elle. Les titres s'affichent alors en Source Sans 3.

Si vous possédez une licence web de Massilia, remplacez ce fichier par le fichier variable WOFF2 de Massilia
(graisses 200 à 900), sous le même nom, puis reconstruisez l'image. Ne le committez pas dans un dépôt public.
